# 国标制图规范与分级验收

新建工程图、用户未指定完整制图标准或进行成图审查时，按本规范补全默认设计与验收标准；已有图纸的局部修改优先沿用原图既有规范。

## 1. 幅面、比例与空间（GB/T 14689 / 14690）

- **模型空间按实物 1:1 绘制**。新建公制工程图默认用毫米，已有建筑或场地图按已知长度确认原单位并沿用；出图缩放通过图纸空间视口或打印比例控制，并在标题栏注明比例。
- **推荐比例**：优先 `1:1`；缩小用 `1:2 / 1:5 / 1:10 / 1:50 / 1:100`，放大用 `2:1 / 5:1 / 10:1`。
- **常用幅面**：A0 `1189×841`、A1 `841×594`、A2 `594×420`、A3 `420×297`（零件图最常用）、A4 `297×210`（装订边 A0–A3 留 25 mm、A4 留 20 mm，其余留 5–10 mm）。

## 2. 图线、线宽与图层铁律（GB/T 17450）

| 类别 | 建议线宽 | 线型 | 典型用途 |
| :--- | :--- | :--- | :--- |
| 粗实线 | `0.50 mm`（或 `0.35 mm`） | Continuous | 可见轮廓线、剖切符号短粗线 |
| 中实线 | `0.25 mm` | Continuous | 图框、标题栏外框 |
| 细实线 | `0.15–0.18 mm` | Continuous | 尺寸线、引线、剖面线（HATCH） |
| 细虚线 | `0.18 mm` | DASHED | 不可见隐藏轮廓线 |
| 细点划线 | `0.18 mm` | CENTER | 对称中心线、轴线、分度圆（超出轮廓 3–5 mm） |

- **ByLayer 铁律**：实体的颜色、线型、线宽一律设为随层（`ByLayer`），不硬编码到单个图元。
- **0 层与 Defpoints 禁忌**：`0` 层仅用于创建块定义（块内图元画在 `0` 层并设 `ByLayer`，基点取在图框左下角/孔中心等合理基准），不在 `0` 层直接画图；不在 `Defpoints` 层绘图。
- **语义分层**：按轮廓、隐藏线、中心线、剖面填充、尺寸标注、图框文字清晰分层，绝不混层。

## 3. 标注、字高与剖视规则

- **标注顺序与三不原则**：按`总体尺寸 → 定位尺寸 → 定型尺寸 → 公差/粗糙度/技术要求`组织；**不封闭尺寸链、不重复标注、不把尺寸标在虚线上**。
- **幅面字高与常用标注变量**：

| 幅面 | 尺寸/技术要求字高（`DIMTXT`） | 标题字高 | 推荐箭头（`DIMASZ`） |
| :--- | :--- | :--- | :--- |
| A0 / A1 | `5.0 mm` | `7.0 mm` | `3.5 mm` |
| A2 / A3 | `3.5 mm` | `5.0 mm` | `2.5 mm` |
| A4 | `2.5 mm` | `3.5 mm` | `2.0 mm` |

- **常用控制符**：`%%c`（Ø 直径）、`%%d`（° 角度）、`%%p`（± 正负号）、`\P`（MTEXT 换行）；直径/半径标注优先使用系统测量值 `<>`（如 `4×<>`），避免手写假数值导致与几何脱节。
- **剖视图与填充铁律**：
  - 全剖/半剖视图除绘制断面轮廓与 45° 剖面线（`ANSI31`）外，**必须画全剖切面后方的可见轮廓线**（如孔腔后壁的上下口与台阶横线），严禁把连续零件画成断开的“浮空孤岛”。
  - 剖面填充（`HATCH`）必须基于闭合边界，内孔作为岛排除，严禁漏填或溢出到孔腔内。
- **工程边界诚实**：缺少材料、公差、热处理或配合间隙等关键制造参数时，在技术要求中标明“待复核”，不编造加工精度，不把示意草图冒充可加工施工图。

## 4. L1–L4 分级验收与熔断纪律

执行结束不等于图纸正确，按由浅入深四级核验（常规草图至 L3，正式交付/出图必须过 L4）：

- **L1 执行回执**：脚本/命令返回成功（最低信任，不可单独作为完成依据）。
- **L2 数量与清洁**：实体总数符合预期，无多余空文字、重复重叠线或残留测试图元。
- **L3 结构审计**：重开交付文件后，按 `(实体类型, 图层)` 分类核对关键坐标、尺寸测量值、轮廓闭合性、原生标注类型与 `doc.audit()` / 图面一致性。
- **L4 视觉交叉审查**：查看同版导出的 PDF/渲染图，专门抓取纯数据漏掉的问题——中文与数字字体统一无乱码、粗细线宽对比清晰、虚线/中心线比例正确、标注与视图名无压线重叠、剖视后壁轮廓连通、标题栏留白充足。

**迭代与熔断**：先修 L3 结构/坐标硬伤，再修 L4 排版美观；同一类错误连续失败 **3 次** 或出现坐标系/活动文档上下文异常时立即熔断停手，排查根因后再继续，不盲目重跑。

## 建筑改版与出图验收

- **从底模定位。** 用同层平面或剖切面叠合 CAD 与底模，以已知长度及至少两个分开的对应点核对单位、原点与朝向。对本轮涉及的柱逐层逐根核对轴线位置、截面大小和方向。弧形立面沿原内外弧核对半径或曲线轮廓、两端收口；涉及坡道时，同时核对两端标高，再布置门窗、格栅和饰面。
- **按本轮变更核对各份交付物。** 例如移动开水间隔墙，复测模型净面积，核对平面墙位、门洞、门扇开启和房间表，再读同版 PDF 的印出值。天窗数量或位置变化时，核对屋顶模型、屋顶平面、相关剖面及图纸说明。以任务约定的底图或模型为准，保留已批准的设计差异。
- **核对打印尺寸。** 对本轮新增或受影响的每种标注样式与出图比例组合，选一条可定位的尺寸，从几何端点独立实测，按标注单位和精度换算后，与 DWG 显示文字及最终 PDF 同一处读数逐项核对。例如 9,525 mm 的尺寸在 1:100 视口内仍应印为 9,525 mm。发现倍率或文字异常时检查样式的线性比例因子、对象级覆盖及替代文字，排查同样式与同类覆盖的全部标注，修正后重新出图复读。
